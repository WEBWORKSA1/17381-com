# 17381.com — 17381 Numbers Lab

Free business, money & AI calculators, an any-number analyzer and plain-English guides. Static site (HTML/CSS/vanilla JS), hosted on GitHub Pages from `main` (root) with custom domain `17381.com`.

- Research & idea selection: `RESEARCH.md`
- Phase-wise build prompts: `BUILD-PROMPTS.md`
- Monetisation: Google AdSense (`ads.txt` included), lead generation (`/checkup.html`), sponsorships (`/advertise.html`), supporter pledges (`/support.html`), contests (`/contests.html`), hiring (`/careers.html`).
- All forms post via AJAX to a private inbox; the address is assembled at runtime and never appears in page source.

## Structure
- `index.html`, `number.html` (Number Analyzer), `17381.html`, `tools.html` + `tools/*`, `guides.html` + `guides/*`, `videos.html`
- Lead gen & community: `checkup.html`, `support.html`, `contests.html`, `rules.html`, `careers.html`, `advertise.html`, `contact.html`
- Legal: `about.html`, `privacy.html`, `terms.html`, `cookies.html`, `disclaimer.html`, `editorial-policy.html`, `trademark.html`
- Assets: `assets/css/main.css`, `assets/js/main.js`

How it works

A positional number system with base b gives each digit a weight of b raised to its position. To convert into decimal, multiply each digit by its weight and add. To convert out of decimal, repeatedly divide by the target base and read the remainders from last to first.

Worked example

Hex 43E5 = 4×16³ + 3×16² + 14×16 + 5 = 16,384 + 768 + 224 + 5 = 17,381. In binary that is 100001111100101 and in octal 41745.

Where you will meet each base

  • Binary (2): bits, flags, network masks.
  • Octal (8): Unix file permissions such as 755.
  • Hexadecimal (16): colours (#3EE6B0), memory addresses, hashes.
  • Base 36: compact IDs and short links using 0–9 and A–Z.

Frequently asked questions

Why is hexadecimal popular?

One hex digit maps exactly to four binary bits, so long binary values become short and readable.

Is this case-sensitive?

No. Letters A–Z can be entered in upper or lower case.
